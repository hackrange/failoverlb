Maps

nginx's lookup table. Read one thing, set another, and use the answer anywhere a setting takes a value.
{% if can('edit_sites') %} {% endif %} {% if can('apply_config') %} {% endif %}
A map is how you do conditional things without piling up if blocks, which nginx handles badly inside a location. It looks at one variable, works down its list top to bottom, takes the first match, and puts the answer in a variable of your own. Then you use that variable in a setting, in a header value, or in raw config.
