Utilization

What the boxes are actually doing, over time. A number on its own tells you this second; a line tells you whether it is normal.

What is not on this page

Per site and per backend numbers. Request rates, status code mix and latency percentiles broken down by site need the access log read and parsed, which is not built. The log format already carries everything it would need. See docs/plus-parity.md.

CPU and memory for the backends in a pool. These are somebody else's servers and there is no agent on them. The plan is to read a metrics endpoint they already expose rather than hold credentials for every backend, which would turn this into something with the keys to the estate.

Anything older than a couple of hours. The numbers are kept in memory, so a restart of the manager loses the history and nothing is written to disk. That is on purpose: a table that grows forever on a load balancer is a way to fill a disk, and a full disk on a load balancer is a worse outage than a missing chart.
