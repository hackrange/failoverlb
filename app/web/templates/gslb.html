A load balancer can only move traffic that reaches it. If the whole node is gone, nothing reaches it, and the only thing left that can send people somewhere else is DNS. These nodes answer DNS themselves for the names you list here, and they leave out any node that is not answering. Your domain host has to point the name at these nodes first, which is the delegation shown under each zone.
