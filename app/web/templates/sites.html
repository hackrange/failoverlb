The hostnames this site answers to. nginx matches the Host header a browser sends against these to work out which server block to use.

Examples

  • www.example.com matches only that exact name
  • www.example.com example.com matches both
  • *.example.com matches any subdomain
  • _ is the catch all, used for the default site

Worth knowing

If a request comes in for a name no site claims, nginx uses whichever server block is marked as the default, or the first one it loaded. That is usually not what you want, so it is worth having one site set as the default that returns a plain 404.

Locks this whole site down so only the management networks can reach it.

What it writes

An allow line for every node in the cluster, plus your management networks, then a deny all. The node list is generated from the cluster roster, so when you add a node later it lands in here on its own without anybody having to remember.

When to use it

  • An admin panel or a staging site that should never face the internet
  • An internal API that only your own systems call
  • A metrics or status endpoint
