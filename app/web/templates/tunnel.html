Tunnel

Reach a backend that has no public address. The machine dials out to these load balancers, and your pools reach it back down the same tunnel.
{% if can('manage_cluster') %} {% endif %}
To put a server in a pool it has to be reachable from these load balancers, which normally means a public address and a hole in a firewall. A tunnel avoids both. The machine opens the connection outward, so nothing inbound has to be allowed, and it stays reachable from whichever load balancer is serving.

It is not a VPN. The machine gets a route to these load balancers and nothing else. It does not change where that machine's own traffic goes and it gives it no way out to the internet.
