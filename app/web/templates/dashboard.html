The manager reads nginx -V off this box and works out which modules were compiled in.

Why it matters

Settings for a module you do not have are simply not shown. That way you cannot save a config that nginx will refuse to load. If you want a module that is not here, add it to the module list at the top of nginx-installer.sh and run the install again. The new settings show up on their own once the build is done.

Post quantum

This needs OpenSSL 3.5 or newer, which the installer builds against. It adds a key exchange that holds up even against a future quantum computer, so traffic somebody records today cannot be decrypted years from now.
