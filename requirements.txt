# Backups.  A zip that any tool can open, encrypted with AES-256.
#
# Not the zip format's own encryption, which is ZipCrypto and is broken by a
# known plaintext attack.  A backup here is full of PEM files, which is more
# known plaintext than anybody needs.  The standard library can read an
# encrypted zip and cannot write one, hence a package.
