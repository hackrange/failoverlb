# Failover LB Python dependencies.
#
# Every version is pinned so a rebuild never pulls in a surprise upgrade.
# Bump deliberately, then rebuild and run the smoke tests.
#
#     Last reviewed: August 16, 2026, with trivy against a live CVE feed.
#                    It found twelve HIGH advisories.  The two on the auth
#                    path (a PyJWT token forgery bypass and a path traversal
#                    in python-multipart) were bumped right away.  The rest
#                    (starlette, fastapi, cryptography, SQLAlchemy) need a
#                    major version move and are being done separately.
#     Review again:  quarterly, and immediately for an advisory in any of
#                    the six below that handle untrusted input:
#
#     starlette      every request goes through it
#     fastapi        the same, one layer up
#     Jinja2         renders every page, and the nginx config
#     PyJWT          parses tokens an identity provider sends us
#     cryptography   the cluster CA and every peer certificate
#     SQLAlchemy     every query
#
# The SBOM in sbom/ lists these versions too.
